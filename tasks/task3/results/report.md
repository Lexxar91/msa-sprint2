# Task3: проверка перед сдачей

Проверка выполнена 1 октября 2026 года на изолированном Docker Compose стенде `hotelio-review`. Использованы актуальные исходники подграфов и Gateway. Бизнес-логика при подготовке к сдаче не изменялась.

## Реализация

- Apollo Gateway объединяет подграфы бронирований и отелей и передаёт заголовок `userid`.
- Подграф бронирований запрашивает список через gRPC у Python Booking Service.
- ACL проверяет наличие `userid` и совпадение с аргументом GraphQL-запроса.
- Поле `Booking.hotel` разрешается через федеративный подграф отелей.
- Функции документированы JSDoc; исходники отформатированы Prettier. AST до и после обработки совпадает без учёта документации и расположения текста.

## Фактические результаты

| Сценарий                                                 | Результат                                                       |
| -------------------------------------------------------- | --------------------------------------------------------------- |
| `userid: test-user-2`, запрос своих бронирований         | Данные возвращены, в том числе вложенное поле `hotel`           |
| Заголовок отсутствует                                    | GraphQL-ошибка `Unauthorized: missing userid header`            |
| `userid: test-user-3`, запрос бронирований `test-user-2` | GraphQL-ошибка `Forbidden: you can only view your own bookings` |

Все три HTTP-запроса получили статус 200: ошибки доступа представлены в поле GraphQL `errors`, что не означает успешное выполнение операции.

- [api-responses.json](api-responses.json) — точные ответы всех трёх запросов.
- [docker-ps.log](docker-ps.log) — состояния контейнеров после запуска.
- [services.log](services.log) — фактические логи сервисов.

Порты временного стенда: REST 18084, Gateway 14000, подграфы 14001/14002, gRPC 19091. Обычные порты проекта приведены в корневом README. Временный стенд после проверки удалён.

## Ограничения для сдачи

Подграф отелей возвращает заглушки вместо вызова внешнего сервиса. В gRPC callback подграфа бронирований после `reject` отсутствует ранний выход. Эти замечания относятся к логике и оставлены без исправления по ограничению текущей задачи.

В задании перечислены скриншоты успешного вызова и отказа ACL. Здесь сохранены JSON-ответы и журналы, а не скриншоты; при строгой проверке формата приложите скриншоты из GraphQL-клиента. Полную готовность task3 без устранения перечисленных замечаний считать подтверждённой нельзя.
